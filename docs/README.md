
# Documentation

This directory contains supporting documentation for:

**A Synthetic Email Corpus Annotated with Brown and Levinson's Face Acts and Document-Level Politeness**

## 1. Face Act Annotation Guidelines

Guidelines for sentence-level multi-label Face Act annotation, based on Brown and Levinson's politeness theory.

The annotation scheme includes nine labels:

- HNeg+, HNeg-
- HPos+, HPos-
- SNeg+, SNeg-
- SPos+, SPos-
- Neutral

The guidelines describe label definitions, annotation criteria, and examples.

## 2. Document-Level Politeness Annotation Guidelines

Guidelines for rating emails along three dimensions:

1. Directness vs. Indirectness
2. Positive Face Saving
3. Negative Face Saving

Each dimension is assessed on a five-point scale.

## 3. Synthetic Corpus Generation

Documentation of the synthetic email generation procedure, including:

- Topic extraction and selection
- Request and reply generation
- Four reply types (Accept-Polite, Accept-Impolite, Reject-Polite, Reject-Impolite)
- Generation of five politeness levels

## 4. Generation Prompts

The prompts used to generate and paraphrase the synthetic emails will be documented here.

## Availability

The annotation guidelines and generation prompts will be uploaded as separate files.
