
# LLaMA — Face Act Classification (FAC)

This directory contains the LLaMA-based implementation for sentence-level multi-label Face Act Classification.

## Model

- Backbone: meta-llama/Llama-3.2-1B
- Fine-tuning: Low-Rank Adaptation (LoRA)
- Task: Multi-label Face Act Classification
- Number of labels: 9

## Experimental Configurations

1. Sentence classification — No Context
2. Sentence classification — Mail Context
3. Sentence classification — Pair Context
4. Sequence Labeling — Mail Context
5. Sequence Labeling — Pair Context
