
# BERT — Face Act Classification (FAC)

This directory contains the BERT-based implementations for sentence-level multi-label Face Act Classification.

## Model

- Backbone: bert-base-uncased
- Task: Multi-label classification
- Number of Face Act labels: 9

## Experimental Configurations

Five configurations are evaluated:

1. Sentence classification — No Context
2. Sentence classification — Mail Context
3. Sentence classification — Pair Context
4. Sequence Labeling — Mail Context
5. Sequence Labeling — Pair Context
